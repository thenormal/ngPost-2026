# Common problems

## The login is refused

Check user name and password, the host and the port, and the SSL setting. Use **Test connection**. Do not retry many times in a row: providers can block the account for a while after many wrong logins.

## The upload is slow

Raise the number of connections, up to the limit of your provider. Check that SSL is not slowing an old computer, and that nothing else uses your line.

## "There is no newsgroup" or "newsgroups are not valid"

Open **Settings**, section **Newsgroups**, and add valid names. See [Newsgroups](03-newsgroups.md).

## The NZB file already exists

Choose another name or folder, or accept to overwrite it when the program asks.

## The temporary folder already exists

A previous post was stopped abruptly. Delete the leftover temporary folder of that post and try again.

## Some articles failed

Use **Repost missing articles**. See [Failed articles and repost](07-failed-articles.md).

## I need help

Save the **diagnostic report** (button below the log in Quick Post) and describe the problem on the project page on GitHub.
