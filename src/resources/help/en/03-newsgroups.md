# Newsgroups

The newsgroups are the places on Usenet where your articles are posted. They are set in **Settings**, section **Newsgroups**.

## The groups box

Each newsgroup is a small "chip":

- Type a name and press **Enter**, **Tab**, comma or space to add it.
- While you type, a short list of common groups is suggested.
- Click the **×** on a chip, or press **Backspace** in the empty box, to remove it.
- A name that is not valid (for example without a dot) is shown in red.

A valid name has lowercase letters, digits, `+`, `_` or `-`, separated by dots, for example `alt.binaries.test`.

## Checks before posting

ngPost does not start a post if there is no newsgroup, or if one of them is not valid. The message tells you to fix them in Settings.

## Where the posts go

When you have several groups, the menu next to the box chooses where each article goes:

- **All the groups in every post** (the default): every article is posted in all the groups.
- **One random group for each post**: each post goes to one group of the list, chosen at random.
- **One random group for each file**: each file goes to one random group. This needs the option **Obfuscate Articles** (in Privacy).

Use a test group such as `alt.binaries.test` while you learn. Use the groups your provider and the community expect for real posts.
